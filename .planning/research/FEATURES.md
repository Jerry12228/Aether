# Feature research

原功能初步全集见 docs/FEATURE-PARITY.md；逐项正式盘点由 Phase 1 完成。以下复杂度是工程相对估计，非工期承诺。

| 功能 | 地位 | 复杂度 | 关键依赖 |
|------|------|--------|----------|
| 配对、发现、直连、认证与撤销 | 原能力基线 | 中 | GameStream重构扩展与安全身份 |
| 低延迟单屏桌面/游戏，硬件 codec/输入/音频 | 原能力基线 | 高 | 捕获、编解码、呈现与实时传输 |
| HDR/4:4:4、多声道/手柄/触摸/移动交互 | 原能力基线，按平台条件验收 | 高 | 设备能力、HDR surface、HID 后端 |
| 麦克风上行成为系统设备 | 用户新增硬要求 | 高 | PCM capture endpoint、签名、实时音频 |
| 摄像头上行成为系统设备 | 用户新增硬要求 | 很高 | Win10/11 不同接入方案、媒体采集与权限 |
| 实例独立显示器组、持久应用、原子切换 | 用户新增硬要求 | 高 | 主机协调器、稳定 ID、窗口与资源所有权 |
| 客户端多显示器请求多流 | 用户新增硬要求 | 高 | 拓扑协商、GPU资源预算、客户端多窗/外屏 |
| 在线改码率、可选自动修正 | 用户新增硬要求 | 高 | 编码器重配、反馈、拥塞与多流分配 |
| 剪切板双向同步 | 用户新增；Apollo 参考 | 中 | 系统 API、租约、冲突/大小控制 |
| 单仓库五端交付 | 用户组织与技术硬要求 | 高 | 共享核心、平台 adapters、分平台构建/检查；Apple 实机验证 VFY TODO |

不实施的当前方向：并行多用户隔离桌面、旧协议兼容；明确 TODO：VPN、文件互传、打印、Linux/macOS 服务端。

剪切板初始覆盖文本，独立阶段扩展 HTML/图片等平台可支持的格式；文件对象剪切板涉及真正文件传输时归 FILE-01。不能把文件复制当成单纯同步本地路径。
