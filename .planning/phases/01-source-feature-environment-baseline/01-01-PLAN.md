## Contracts and execution boundaries

- 所有命令从 Aether 根执行；仅 Node 内置模块、Git、PowerShell，无包安装。Level 1 的 runner/Git API 研究已在 RESEARCH 完成；不做产品协议、媒体、UI 或驱动原型。
- `validate-baseline.cjs` 用 CJS；导出 `validateSources({root, scope, data, gitRunner}) -> {errors, counts, blockers}`、`validateAnchor({root, anchor, gitRunner}) -> {errors, blob}`、`renderSourceAudit(data, result) -> string`。require 时不启动 CLI；异常/未知状态不得被吞成成功。
- CLI：`--sources` 仅读 lock/sources；`--scope <repo-name>` 仅用于真实 tracer 子集；`--index-sources` 枚举固定对象并保留人工注释，`--scope` 可限制仓库；`--report docs/SOURCE-AUDIT.md` 显式生成报告。默认无参数为全基线验证，须等 01-03 创建全部数据后才执行。01-02 会添加 `--features`，01-03 添加 `--environment`、测量与完整审阅入口。单链命令不得要求后续数据存在。
- CLI 未知/冲突参数、缺少所选链输入、失败子进程、JSON 不可解析退出非零；成功输出一条非空 JSON 摘要 `status=PASS, scope, checked, errors=0, blockers, pendingDecisions`。结构 PASS 只代表审计记录完整，明确区别生产复用批准。若 `--report`，先验证再原子更新已允许的主仓库文档；验证失败保留现有报告且非零。
- sources 根：`schemaVersion=1, capturedAt, purpose, scope{repoIds,complete}, repositories[], files[], externals[], licenseEvidence[], routes[], decisions[], blockers[]`。ID 唯一；路径统一正斜线；稳定排序 repo/path/id；日期不随读取变化。
- repositories：`name,url,commit,head,remote,checkoutState(clean|dirty|missing|failed),statusEvidence,gitlinkIds`。files：`id,repo,commit,path,blob,mode,kind(source|header|license|docs|asset|generated|binary|build|symlink),licenseEvidenceIds,copyright,exceptionEvidenceIds,reuseIntent(research-only|independent-implementation|copy|modify|link|redistribute|excluded),auditState(identified|blocked),blockerIds`。
- anchor：`repo,commit,path,blob,symbol,startLine,endLine,excerpt`，从 commit 对象核对 blob 和短原文；不能用可变工作树代替。licenseEvidence：`id,anchor,scopePaths,spdxExpression|null,obligations,reviewState(identified|unresolved),blockerIds`。根文本可继承至有证据的范围，独立头部/例外/第三方/资产另审；不确定项标 blocked，不以缺头部得出无版权结论。
- externals：`id,parentRepo,kind(gitlink|download|binary|driver),path,url,commit|null,digest|null,materialization(absent|present|verified),licenseEvidenceIds,blockerIds,requiredByPhases`。未初始化对象可完整登记“无法逐文件核验”的阻碍，不能伪造内部文件证据或默认下载。
- routes：`id,platform,artifactKind,channel,sourceIds,terms[{url,title,version,capturedAt,relevantSections}],obligations,evidenceState(identified|blocked),blockerIds`。decisions：`id,question,options[{id,description,benefits,costs,blockedBy}],recommendation,selected|null,status(pending|selected|blocked),confirmedBy|null,confirmedAt|null`。blockers：`id,description,evidenceIds,affectedRouteIds,requiredByPhases,resolutionNeeded,status(open|resolved)`。
