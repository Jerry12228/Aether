# 后续 TODO

以下功能和验证任务保留在产品方向中，当前 v1 不要求完成。功能晋升时创建需求 ID、独立阶段、来源研究和平台验收矩阵；VFY 项仅延后实机验证，客户端实现与构建仍在 v1。

| ID | 项目 | 必须澄清/验证 |
|----|------|--------------|
| VPN-01 | 服务端与客户端内置 WireGuard | 密钥生命周期、路由/DNS、权限、kill switch、隧道与串流带宽关系 |
| VPN-02 | 服务端与客户端内置 OpenVPN | 核心依赖、凭据、移动平台系统 VPN API、分发与许可 |
| VPN-03 | Selene 连接用户配置的其他 WireGuard | 配置导入、系统 VPN 冲突、多隧道行为、敏感信息存储 |
| FILE-01 | 双向文件互传 | 目录授权、断点续传、路径安全、校验、大小配额、平台文件选择器 |
| PRINT-01 | Helios 打印到客户端 PC/Pad 打印机 | 打印格式、spooler、驱动、iPad/Android 系统打印能力、权限与错误反馈 |
| HOST-01 | Linux 服务端 | Wayland/X11 捕获、输入、虚拟屏、音频、设备回传与驱动策略 |
| HOST-02 | macOS 服务端 | ScreenCaptureKit、TCC 权限、输入、虚拟屏、摄像头/音频设备方案 |
| VFY-01 | iOS/iPadOS 客户端实机验证 | 当前无实机；获得 iPhone/iPad 后验证真实硬解/呈现、音频/采集、权限/后台、控制器/外屏、剪切板/码率/切换、性能及安装/升级 |
| VFY-02 | macOS 客户端实机验证 | 当前无实机；获得 Mac 后验证 VideoToolbox/Metal、音频/采集、权限、键鼠/控制器、多屏/HDR/DPI、睡眠恢复、剪切板/码率/切换、性能及安装/升级 |

VFY-01/VFY-02 不阻塞首版发布。两端始终标记“实现/构建状态”与“实机验证 TODO”，不能把编译、模拟器或自动化测试结果视为实机通过。后续获得硬件后单独规划验证阶段并逐项补齐证据。

额外原功能如在 Phase 1 盘点中发现，先加入 FEATURE-PARITY 与 v1 需求；不能因未在初始列表枚举而自动放到 TODO。
